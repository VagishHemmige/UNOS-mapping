Joining values to the map

The original code split each spreadsheet’s “Region 1: Connecticut, Maine, …” text into seven state columns and pivoted it long, so that it could be joined to a Census shapefile. {sRtr}’s UNOS_regions_sf already records each state’s region, so each study’s table needs only the region name. Every state takes its region’s values. The original code used inner_join(), which silently drops a region whose name is spelled differently. This function stops instead and names the missing region.

Click to show/hide R Code 
# Attach a regional summary to the state polygons. Every state takes its
# region's values. Stops if any region is missing from the summary.
join_region_values <- function(region_states, region_summary) {
  missing_regions <- setdiff(unique(region_states$Region), region_summary$region)
  if (length(missing_regions) > 0) {
    stop(
      "The regional summary has no row for: ",
      str_flatten_comma(sort(missing_regions))
    )
  }
  region_states |>
    left_join(
      region_summary,
      by = join_by(Region == region),
      relationship = "many-to-one"
    )
}

Choosing the transplant centers

The HRSA layer that get_hrsa_transplant_centers() downloads has one row for each center and organ, so a center that transplants five organs appears five times. The function keeps centers that list the organ, then one row per center code (OTC_CD). It then applies the original maps’ rule for pediatric centers (analysis plan section 5), and drops centers outside the mapped states. Without that last step, a center in Puerto Rico appears in the sea south-east of Florida.

# Keep centers that list the organ, one row per center, excluding pediatric
# centers by name. The HRSA layer has one row per center and organ, so
# distinct() is needed or each center is drawn several times.
# Centers outside the mapped states (Alaska, Hawaii, Puerto Rico) are dropped,
# since the map shows only the 48 contiguous states and DC.
select_adult_centers <- function(centers, organ, adult_exceptions,
                                 mapped_states, crs) {
  centers |>
    filter(str_detect(Service_Lst, str_c("\\b", organ, "\\b"))) |>
    distinct(OTC_CD, .keep_all = TRUE) |>
    filter(!str_detect(OTC_NM, "Children") | OTC_NM %in% adult_exceptions) |>
    st_transform(crs) |>
    st_filter(mapped_states)
}

Placing the region numbers

On the main map, a region that the corridor box touches is labelled on the part of it that lies outside the box, enlarged by label_margin, so no number sits under the red outline. In the inset, each region the box touches is labelled on its part inside the box, shrunk by the same margin, so every region the enlarged view shows has its number. st_set_agr("constant") tells sf that a region’s name applies to every piece of it, which silences a warning when the regions are cut.

Click to show/hide R Code 
# Points for the region numbers. On the main map, a region that the corridor
# box touches is labelled on its part outside the box (enlarged by `margin`
# metres), so no number sits under the box's outline. In the inset, each
# region is labelled on its part inside the box (shrunk by `margin`), so every
# region the inset shows gets its number.
place_region_labels <- function(region_outlines, box, margin, where) {
  regions <- region_outlines |>
    st_set_agr("constant")
  touched <- lengths(st_intersects(regions, box)) > 0

  if (where == "main") {
    outside_parts <- regions |>
      filter(touched) |>
      st_difference(st_buffer(box, margin))
    label_areas <- bind_rows(filter(regions, !touched), outside_parts)
  } else {
    label_areas <- regions |>
      filter(touched) |>
      st_intersection(st_buffer(box, -margin))
  }

  label_areas |>
    st_set_agr("constant") |>
    st_point_on_surface() |>
    mutate(label = str_remove(Region, "Region "))
}

  )

The map, in ggplot2

This replaces the original maps’ geom_sf() calls with several changes. The plot is drawn in map_crs (coord_sf(crs = ...)) rather than in longitude and latitude, so the country is not stretched east to west. Centers are drawn with geom_sf() at their true locations; the original geom_jitter() moved each point randomly by up to 0.3 degrees, which is about 30 km. Mapping the centers’ shape to center_label gives them their own legend entry. Region numbers sit on a pale box (geom_sf_label()) so they read on any fill colour. The note in the caption says what the shading and the dots are, so a figure taken off this site still explains itself. Text is sized from base_size, in points.

Click to show/hide R Code 
# Map one measure: states shaded by region value, region outlines on top,
# region numbers on a pale box so they read on any fill, transplant centers
# at their true locations with their own legend entry, and a note saying
# what the shading and the dots are.
map_regions_ggplot <- function(region_states, region_outlines, region_labels,
                               fill_var, legend_title, centers, center_label,
                               note, palette, na_fill, crs, base_size) {
  ggplot() +
    geom_sf(
      data = region_states,
      mapping = aes(fill = .data[[fill_var]]),
      colour = "grey55",
      linewidth = 0.2
    ) +
    geom_sf(data = region_outlines, fill = NA, colour = "black", linewidth = 0.4) +
    geom_sf(
      data = centers,
      mapping = aes(shape = center_label),
      size = 1,
      alpha = 0.6
    ) +
    geom_sf_label(
      data = region_labels,
      mapping = aes(label = label),
      colour = "navy",
      fill = alpha("white", 0.75),
      fontface = "bold",
      size = base_size / .pt
    ) +
    scale_fill_continuous_sequential(palette = palette, na.value = na_fill) +
    scale_shape_manual(values = 16, name = NULL) +
    coord_sf(crs = crs, datum = NA) +
    labs(fill = legend_title, caption = str_wrap(note, 110)) +
    theme_void(base_size = base_size) +
    theme(
      plot.caption = element_text(hjust = 0, size = base_size * 0.8),
      legend.position = "right"
    )
}

The map, in tmap, with a corridor inset

Between Washington and Boston, transplant centers crowd so closely that they overlap on a national map. The map’s layers are written once, in map_layers(), and used twice: for the main map and, with bbox set to the corridor, for the inset. Building the inset as its own map, rather than giving tm_inset() a bounding box, lets it carry its own region numbers (inset_labels); a red outline of corridor_box on the main map shows where it is. tm_pos_out() places the inset outside the map frame, to the right, and the colour legend, the center symbol (tm_add_legend()) and the note (tm_credits()) along the bottom, so none of them hides any part of the country. One difference from {ggplot2}: {tmap} takes the palette as a vector of colours, which has to be reversed (rev = TRUE) so that high values get the dark end, as they do in scale_fill_continuous_sequential().

# The same map in tmap, with the Washington-Boston corridor enlarged in an
# inset beside it. The inset is drawn as its own map, so it carries its own
# region numbers, and a red box on the main map shows where it is. The legend,
# the center symbol and the note run along the bottom.
map_regions_tmap <- function(region_states, region_outlines, main_labels,
                             inset_labels, fill_var, legend_title, centers,
                             center_label, inset_box, note, palette, na_fill) {
  # rev = TRUE puts the dark end of the palette on high values, matching
  # scale_fill_continuous_sequential() in the ggplot2 maps
  fill_scale <- tm_scale_continuous(
    values = sequential_hcl(7, palette = palette, rev = TRUE),
    value.na = na_fill
  )

  # The layers shared by the main map and the inset
  map_layers <- function(labels, bbox, fill_legend) {
    tm_shape(region_states, bbox = bbox) +
      tm_polygons(
        fill = fill_var,
        fill.scale = fill_scale,
        fill.legend = fill_legend,
        col = "grey55",
        lwd = 0.5
      ) +
      tm_shape(region_outlines) +
      tm_borders(col = "black", lwd = 1) +
      tm_shape(centers) +
      tm_dots(size = 0.15, fill_alpha = 0.6) +
      tm_shape(labels) +
      tm_text(
        "label",
        col = "navy",
        fontface = "bold",
        size = 0.55,
        bgcol = "white",
        bgcol_alpha = 0.75
      )
  }

  corridor_map <- map_layers(inset_labels, st_bbox(inset_box), tm_legend_hide())

  map_layers(
    main_labels,
    NULL,
    tm_legend(
      title = legend_title,
      orientation = "landscape",
      position = tm_pos_out("center", "bottom")
    )
  ) +
    tm_shape(inset_box) +
    tm_borders(col = "red", lwd = 1) +
    # Outside the map frame, to the right, so it hides nothing on the map
    tm_inset(
      corridor_map,
      position = tm_pos_out("right", "center"),
      width = 16,
      height = 16,
      frame = FALSE
    ) +
    tm_add_legend(
      type = "symbols",
      labels = center_label,
      fill = "black",
      size = 0.4,
      position = tm_pos_out("center", "bottom")
    ) +
    tm_credits(
      str_wrap(note, 105),
      position = tm_pos_out("center", "bottom"),
      size = 0.6
    ) +
    tm_layout(frame = FALSE)
}

Saving

Each map is saved in both versions under figures/<study>/, in three formats: PNG at 300 dpi for the website, PDF (vector) and LZW-compressed TIFF at tiff_dpi for a journal. The size, 7 by 4.6 inches, fits a double-column figure.

Click to show/hide R Code 
# Save the ggplot2 and tmap versions of one map under figures/<study>/, each
# as PNG (for the website), PDF (vector, for a journal) and TIFF at `dpi`.
save_region_maps <- function(ggplot_map, tmap_map, study, name, width, height,
                             dpi) {
  out_dir <- file.path("figures", study)
  dir.create(out_dir, showWarnings = FALSE, recursive = TRUE)

  ggplot_file <- file.path(out_dir, name)
  ggsave(str_c(ggplot_file, ".png"), ggplot_map,
         width = width, height = height, dpi = 300, bg = "white")
  ggsave(str_c(ggplot_file, ".pdf"), ggplot_map,
         width = width, height = height, bg = "white")
  ggsave(str_c(ggplot_file, ".tiff"), ggplot_map,
         width = width, height = height, dpi = dpi, bg = "white",
         compression = "lzw")

  tmap_file <- file.path(out_dir, str_c(name, "_inset"))
  tmap_save(tmap_map, str_c(tmap_file, ".png"),
            width = width, height = height, units = "in", dpi = 300)
  tmap_save(tmap_map, str_c(tmap_file, ".pdf"),
            width = width, height = height, units = "in")
  tmap_save(tmap_map, str_c(tmap_file, ".tiff"),
            width = width, height = height, units = "in", dpi = dpi,
            compression = "lzw")
}
