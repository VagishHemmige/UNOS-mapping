About

Author

Vagish Hemmige

The study

This site reproduces the regional maps from published heart-transplantation studies that used the UNOS registry (Madan et al. 2021, 2024, 2025), and teaches how to draw them with the sRtr package (Hemmige and Czeresnia 2026). The maps’ values come from the published analyses and are public.

  • Shivank Madan (principal investigator of the studies)
  • Vagish Hemmige (mapping and code)

Scientific decisions are made by the people named in AGENTS.md; open ones are listed in SETUP-NOTES.md until they are filed in Issues.

This repository

R/main.R runs the scripts in order: setup, shared map layers, then one script per study. The region geography and transplant centers come from sRtr. Each study’s regional counts, published in its paper, are written out in its script. The original RMDs are kept unchanged in original/.

Contributions follow the rules in AGENTS.md.

How this website was created

The site is built with Quarto from the scripts themselves. Each code page imports the labelled sections of its script from R/ and shows them with an explanation; the site never runs the analysis.

The repository was set up with the R Analysis Workflow plugin and an AI assistant (Claude), working on branches and through pull requests reviewed by the maintainer.

Four documents describe the project. In short: the plan is the scientific intent, the architecture is the workflow as implemented, and AGENTS.md holds the rules for working together.

  • Analysis plan: what the maps are meant to show, and why.
  • Architecture: how the code does it.
  • AGENTS.md: how people and AI assistants work on the project.
  • Repository blueprint: the layout every project of this kind starts from.

## The study

This site reproduces the regional maps from published heart-transplantation studies that used the UNOS registry [@madan2021hcv; @madan2024dcd; @madan2025evmp], and teaches how to draw them with the sRtr package [@srtr_package]. The maps' values come from the published analyses and are public.

-   **Shivank Madan** (principal investigator of the studies)
-   **Vagish Hemmige** (mapping and code)

Scientific decisions are made by the people named in [`AGENTS.md`](agents.qmd); open ones are listed in `SETUP-NOTES.md` until they are filed in [Issues](https://github.com/VagishHemmige/UNOS-mapping/issues).

## This repository

`R/main.R` runs the scripts in order: setup, shared map layers, then one script per study. The region geography and transplant centers come from sRtr. Each study's regional counts, published in its paper, are written out in its script. The original RMDs are kept unchanged in `original/`.

Contributions follow the rules in [`AGENTS.md`](agents.qmd).
