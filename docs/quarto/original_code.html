The R Markdown files that drew the published maps, kept in original/ as the provenance of each map. They are shown here for comparison and are never run. The only change from the files as written is that the folder paths on the author’s computer have been removed, leaving the file names.

All three map RMDs share one pipeline: split a spreadsheet’s “Region N: state, state, …” text into states, join the states to a Census shapefile, dissolve them into regions with st_union(), read a downloaded HRSA center file, and plot in longitude and latitude. The Map geography and Functions pages show what replaces each step.

Two things in the originals are worth noticing when reading them:

  • geom_jitter() draws each transplant center up to 0.3 degrees from where it is, so neighbouring centers do not overlap but no center is where it should be.
  • In the Chagas RMD (not yet part of this site), the map saved as “with centers” was the map without them, because ggsave() was given the wrong plot object. The DCD and EVMP RMDs fixed this.

#Import UNOS region data
UNOS_regions <- UNOS_regions <- 
  #Import Shivank's data from UNOS regions into R
  read_excel("UNOS regions.xlsx") %>%
  #Split column that contains Regions and which states they contain
  separate(Region, c("Region", "B"),sep=":") %>%
  #Split list of states into 7 separate variables
  separate(B, c("State1","State2","State3","State4", "State5", "State6", "State7"), ,sep=",") %>%
  #Trim leading spaces
  mutate_at(vars(contains("State")), str_trim) %>%
  #Change to long format and drop extraneous variable that results
   pivot_longer(
   cols = starts_with("State"),
   names_to = "StateNumber",
   values_to = "State",
   values_drop_na = TRUE) %>%
  select(-StateNumber) %>%
  #Convert percentage variable into percentage (it imports as a raw proportion)
  mutate(Percentage_HT_HCV=100*Percentage_HT_HCV) %>%
  mutate(Percentage_HT_total=100*Percentage_HT_total)
  

#Import State level data
us_states <- read_sf("cb_2018_us_state_20m/cb_2018_us_state_20m.shp") %>%
  select(NAME, geometry) %>%
  filter(!(NAME %in% c("Alaska", "Hawaii", "Puerto Rico"))) %>%
  rename(State=NAME)

#Import region labels
UNOS_region_labels <- read_excel("UNOS region labels.xlsx")

#Import transplant centers
Transplant_centers <- read_csv("Transplant centers.csv") %>%
  select(OTCName, OrganTransplantationCenterServiceTypeDescription, Latitude, Longitude) %>%
  filter(OrganTransplantationCenterServiceTypeDescription=="Heart")

#Looked into removing centers with "Children" in the name, but some may also have adults?
Transplant_centers<-Transplant_centers %>%filter(str_detect(Transplant_centers$OTCName,"Children")=="FALSE" | 
                               (OTCName %in% c("Memorial Regional Hospital/Joe DiMaggio Children's Hospital", 
                                                "Providence Sacred Heart Medical Center & Children's Hospital")))

#Merge files


MergedStates<-inner_join(UNOS_regions, us_states, by="State") %>%st_as_sf()

UNOS_region_map<-MergedStates%>%  
  group_by(Region) %>% 
  summarize(geometry = st_union(geometry))

ShivankMap20210214<-ggplot()+

                                color="black", size = 0.25)+

  theme_void()+

ggplot()+

The R Markdown files that drew the published maps, kept in [`original/`](https://github.com/VagishHemmige/UNOS-mapping/blob/main/original) as the provenance of each map. They are shown here for comparison and are never run. The only change from the files as written is that the folder paths on the author's computer have been removed, leaving the file names.

All three map RMDs share one pipeline: split a spreadsheet's "Region N: state, state, ..." text into states, join the states to a Census shapefile, dissolve them into regions with `st_union()`, read a downloaded HRSA center file, and plot in longitude and latitude. The [Map geography](map_geography.qmd) and [Functions](functions.qmd) pages show what replaces each step.

Two things in the originals are worth noticing when reading them:

- `geom_jitter()` draws each transplant center up to 0.3 degrees from where it is, so neighbouring centers do not overlap but no center is where it should be.
- In the Chagas RMD (not yet part of this site), the map saved as "with centers" was the map without them, because `ggsave()` was given the wrong plot object. The DCD and EVMP RMDs fixed this.
