# Regional summary spreadsheets

One spreadsheet per study, one row per UNOS region, with the region-level values published in each paper. File names are those the original RMDs used, and are set in `R/setup.R` (`region_files`):

| Study | File |
|---|---|
| HCV donors, 2021 | `UNOS regions.xlsx` |
| DCD donors, 2024 | `DCD by UNOS regions.xlsx` |
| Machine perfusion, 2025 | `DBD EVMP UNOS regions_corrected.xlsx` |

The `Region` column holds text such as "Region 1: Connecticut, Maine, ...".
